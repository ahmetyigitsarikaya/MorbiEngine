# Support & Getting Help

Morbi Engine is in **early active development**. Before opening an issue, please check the existing documentation:

- **Getting Started & Build Guide:** [`docs/development/BUILDING.md`](docs/development/BUILDING.md)
- **Dependency Reference:** [`docs/development/DEPENDENCIES.md`](docs/development/DEPENDENCIES.md)
- **Architecture Overview:** [`docs/architecture/OVERVIEW.md`](docs/architecture/OVERVIEW.md)
- **Graphics & Rendering Docs:** [`docs/architecture/GRAPHICS_ARCHITECTURE.md`](docs/architecture/GRAPHICS_ARCHITECTURE.md)
- **Project Roadmap & Status:** [`docs/road/MORBI_ENGINE_ROADMAP.md`](docs/road/MORBI_ENGINE_ROADMAP.md) & [`docs/road/STATUS.md`](docs/road/STATUS.md)

## Where to Ask Questions

- **Bug Reports:** Open an issue using the **Bug Report** or **Graphics & Rendering Issue** template.
- **Feature Ideas & Architecture Discussions:** Open a **Feature Proposal** issue or use GitHub Discussions (if enabled).
- **Security Issues:** Follow [`SECURITY.md`](SECURITY.md) — do not post security vulnerabilities publicly.

> **Note on Platform Support:** Windows 10/11 x64 (MSVC) is currently the only build-verified platform. Linux and macOS support are not yet verified.
