# Roadmap & Architecture Proposals

This directory stores proposals for newly discovered Work Packages (`WP`), Phases, or major architectural designs awaiting approval before implementation.

## Governance Rules

1. New WPs or Phases may be discovered and documented at any time.
2. No unapproved WP, Phase, or implementation may be started or silently folded into an active WP.
3. Every proposal must include technical evidence, scope, dependencies, acceptance criteria, affected modules, and risk analysis.
4. Proposals are tracked in [MORBI_ENGINE_ROADMAP.md](../MORBI_ENGINE_ROADMAP.md) until approved.
