# Code of Conduct

## Our Pledge

We are committed to fostering an open, welcoming, and technically constructive community around **Morbi Engine**, regardless of experience level, background, or identity.

## Expected Behavior

- Communicate respectfully, clearly, and constructively in issues, pull requests, and reviews.
- Critique code and technical tradeoffs—never individuals.
- Be transparent about limitations, unknowns, and early-development constraints.
- Respect maintainers' time by following issue templates and reading existing documentation first.

## Unacceptable Behavior

- Harassment, personal attacks, discriminatory language, or trolling.
- Publishing private or confidential information (such as personal paths, credentials, or private messages) without consent.
- Deliberately submitting malicious code or misleading technical claims.

## Enforcement

Project maintainers may remove comments, close issues/PRs, or restrict participation for behavior that violates these standards. Report concerns directly to the repository maintainer.
